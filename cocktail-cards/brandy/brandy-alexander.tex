\subsubsection{Brandy Alexander}
\noindent

\begin{minipage}{.48\textwidth}

    \textbf{\large Brandy}\\
    \sweettartguage{-0.4}\index[drinks]{Sweet!40\%!Brandy Alexander}

\vspace{.5em}\hrule\vspace{.5em}
\noindent
\textbf{\large Flavor Profile:} Sweet\index[flavor-profile]{Sweet}, Creamy\index[flavor-profile]{Creamy}, Chocolate\index[flavor-profile]{Chocolate}, Caramel\index[flavor-profile]{Caramel}/Vanilla\index[flavor-profile]{Vanilla} from the Brandy.
\vspace{.5em}\hrule\vspace{.5em}
\noindent
\textbf{\large History:} The Brandy Alexander was most likely created in the early 1920's by bartender Troy Alexander. The cocktail was created for a party celebrating clean coal, and he wanted to create a "white" cocktail to represent the fictional clean coal character Phoebe Snow. This version was made with gin, but an unknown bartender took the recipe and changed it to brandy. This was also a favorite cocktail of John Lennon, who famously would say it tasted like a boozy chocolate milkshake.
\vspace{.5em}\hrule\vspace{.5em}
\noindent
\begin{minipage}[t]{.48\textwidth}
    \noindent
    \textbf{\large Ingredients}
    \begin{itemize}
        \item Cognac 45ml\index[ingredient]{Cognac}
        \item Crème de Cacao 30ml\index[ingredient]{Crème de Cacao}
        \item Heavy Cream 30ml\index[ingredient]{Heavy Cream}
    \end{itemize}
    \noindent
    \textbf{\large Garnish}
    \begin{itemize}
        \item Ground Nutmeg\index[ingredient]{Nutmeg}
    \end{itemize}
\end{minipage}
\hspace{.01\textwidth}\vrule\hspace{.01\textwidth}
\begin{minipage}[t]{.48\textwidth}
    \noindent
    \textbf{\large Tools/Glassware}
    \begin{itemize}
        \item Shaker
        \item Strainer \& Fine Strainer (optional)
        \item Jigger
        \item Microplane
        \item Coupe\index[glass]{Coupe} or Martini Glass\index[glass]{Martini Glass}
    \end{itemize}
\end{minipage}
\vspace{.5em}\hrule\vspace{.5em}
\noindent
\begin{minipage}{\textwidth}
    \noindent
    \textbf{\large Instructions}
    \begin{itemize}
        \item Place all ingredients into a shaker.
        \item Add ice and shake for 20 seconds.
        \item Double strain into coupe or martini glass.
        \item Garnish with fresh ground nutmeg using microplane.
    \end{itemize}
\end{minipage}
\vspace{.5em}\hrule\vspace{.5em}
\noindent
\textbf{\large Fun Tip:} For a stronger "chocolate milkshake" flavor add more créme de cacao and less brandy.
